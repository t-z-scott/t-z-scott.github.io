# OSINT / Reconnaissance
- [nmap](https://github.com/nmap/nmap) - network scanning and host discovery tool
- [GoBuster](https://github.com/OJ/gobuster) - discover hidden URLs, files, and directories within websites 
	- This helps to remove/secure hidden files and sensitive data & securing sub-domains and virtual hosts from being exposed to the internet.

# Blue Team
## Data / File Analysis
- [CyberChef](https://github.com/gchq/CyberChef) - encoding, decoding, compression, decompression, parsing, and analyzing data or files
- [steghide](https://steghide.sourceforge.net/) - [*steganography*](https://en.wikipedia.org/wiki/Steganography) program, hide and reveal info in photos
